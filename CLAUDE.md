## Goals

- **Full SEO control**: meta tags, Open Graph, canonical URLs, sitemap — all hand-rolled, no plugin magic
- **Blog**: write articles in Markdown, git-versioned, no CMS needed
- **Flexibility**: own the code completely, no Google Sites / page-builder constraints
- **Performance**: static output, near-zero JS

## Tech stack

- **Framework**: Astro (static output)
- **Styling**: Tailwind CSS v4 (config lives in `src/styles/global.css` via `@theme`, no `tailwind.config.js`)
- **Fonts**: Inter via Google Fonts (loaded in `src/layouts/Layout.astro`)
- **Sitemap**: `@astrojs/sitemap` — auto-generated, requires `site` set in `astro.config.mjs`
- **Package manager**: npm

## Design system

- **Tone**: Minimal & clean
- **Palette**: Navy (`--color-navy-*`) on warm white (`--color-warm-*`) — custom tokens defined in `src/styles/global.css`
- **Key colors**: `navy-950` headings · `navy-700` body · `navy-500` accents · `warm-50` background
- **Max content width**: `max-w-3xl` centered with `px-6` padding
- **Mobile-first**: every page and feature must be responsive — use Tailwind responsive prefixes (`sm:`, `md:`) for all layouts, font sizes, and spacing; default to stacked/single-column on mobile, side-by-side on `sm:` and up

## Project structure

```
src/
  components/
    SEO.astro          # Reusable SEO head (meta, OG, Twitter card)
  content/
    blog/              # Blog posts as .md files (Content Collections)
  content.config.ts    # Blog collection schema (title, description, pubDate, tags, draft)
  layouts/
    Layout.astro       # Base layout: nav, main slot, footer
  pages/
    index.astro        # Homepage
    about.astro        # About page
  styles/
    global.css         # Tailwind import + @theme tokens + base html styles
```

## Deployment

The site is deployed on **Cloudflare Pages**, connected to the GitHub repo. Every `git push` to `main` triggers an automatic redeploy — no manual steps needed.

- **Live URL**: https://christiansisti.com
- **Preview URL**: https://christiansisti-com.pages.dev
- **Cloudflare dashboard**: https://dash.cloudflare.com → Workers & Pages → `christiansisti-com`
- **GitHub repo**: https://github.com/christiansisti/ChristianSisti.Com
- **Build command**: `npm run build`
- **Output directory**: `dist`

### DNS

The domain `christiansisti.com` is registered on **Squarespace**. DNS is managed there:

- **Squarespace DNS settings**: squarespace.com → Domains → `christiansisti.com` → DNS Settings
- `www` CNAME → `christiansisti-com.pages.dev` (points to Cloudflare Pages)
- Apex `@` A record → Squarespace forwarding (redirects to `www`)

### Analytics & SEO

- **Google Analytics**: property `G-NKX4LWTHDS` — tracking script in `src/layouts/Layout.astro`
- **Google Search Console**: submit sitemap at `https://christiansisti.com/sitemap-index.xml`
- **Sitemap**: auto-generated by `@astrojs/sitemap` on every build

## Content

- Blog posts go in `src/content/blog/` as `.md` files
- Blog images go in `src/assets/blog/YEAR/article-slug/` (e.g. `src/assets/blog/2026/my-post/`)
- Required frontmatter: `title`, `description`, `pubDate`
- Optional: `tags`, `draft` (drafts are excluded from listings), `updatedDate`, `heroImage`, `heroImageAlt`, `heroImageCredit`
- Book covers go in `src/assets/books/`

`https://christiansisti.com` — set in `astro.config.mjs` (required for sitemap and canonical URLs)
